# Инструкция кассира / Cashier employee guide

**Язык интерфейса приложения: только английский (English only).**  
На экране нет русских кнопок — ниже шаги на русском, а подписи UI — как на мониторе.

**Product UI language: English only.** Follow the English labels on screen.

---

## Запуск / Launch

1. На рабочем столе RDP откройте ярлык **Promocode Checker**  
   (или запустите `desktop\launch-cashier.ps1` — см. IT / [`../../desktop/README.md`](../../desktop/README.md)).
2. Вверху слева:
   - **Shop** — код точки (например `shop_01`)
   - **User** — имя Windows-сессии RDP (или значение из config), чтобы было видно, кто за кассой
3. Вверху справа лампочка:
   - **Ready** (зелёная) — можно работать
   - **DB not initialized** / **Check failed** / **API unavailable** (жёлтая) — вызовите IT
   - **Connecting…** / **Offline** / **Database offline** — нет связи с сервером, вызовите IT

Не начинайте сканирование, пока не горит **Ready**.

---

## Сканирование промокода / Scan

1. Поле ввода всегда в фокусе (не кликайте мышкой без нужды).
2. Отсканируйте штрихкод или введите **ровно 8 цифр**.
3. В панели статуса: крупный статус + код + **короткая инструкция на английском** (что делать дальше).

| На экране (English) | Что делать (кратко) |
|---------------------|---------------------|
| **READY TO SCAN** | Сканируйте штрихкод клиента (8 цифр) или введите и Enter |
| **ACTIVE** | Код хороший: скидка в кассе POS, затем **Apply discount** |
| **APPLIED** | Скидка записана — можно следующего клиента |
| **USED** | Уже использован — скидку повторно не давать |
| **EXPIRED** | Срок вышел — не принимать |
| **NOT FOUND** | Кода нет — проверить штрихкод / супервайзер |
| **INVALID FORMAT** | Нужны ровно 8 цифр — сканировать снова |
| **ERROR** | Связь/сервер — подождать и повторить или IT |

4. Если статус **ACTIVE** — кнопка внизу станет зелёной: **Apply discount**.  
   Нажмите её после того, как скидка внесена в кассовую программу (offline POS).
5. После успешного применения статус станет **APPLIED**.

Кнопка **Apply discount** неактивна (серая), пока код не **ACTIVE** или система не **Ready**.

## Если что-то не так / If something fails

| Ситуация | Действие |
|----------|----------|
| Лампочка не **Ready** | Не сканируйте; сообщите IT / смене |
| **NOT FOUND** / **USED** / **EXPIRED** | Не нажимайте **Apply discount**; проверьте код с клиентом / IT |
| **ERROR** / Internal Server Error | Сообщите IT; подождите восстановления **Ready** |
| Сканер не печатает цифры | Проверьте раскладку, фокус в поле, кабель; IT |

Не закрывайте окно браузера вручную, если IT настроил режим приложения (app mode).
